# 제출용 시연 녹화

디버그 APK를 사용한다. 실제 기관에 발신하지 않으며 보험사 접수는 모의 연동이다.

## 이 Mac에서 실행

Android SDK와 Pleos ARM64 이미지는 저장소 옆 android-sdk에 설치한다. AVD는 Pleos_Codex이며 Android 사용자 설정은 옆 android-user에 둔다. cold boot, RAM 4GB로 실행한다.

앱은 Pleos 하단 독에서 열고 화면을 유지한다. 녹화는 실제 에뮬레이터 화면을 MP4로 저장하며 음성은 포함하지 않는다. 설명 음성은 별도로 추가한다.

- `tools/record-demo.sh S13 30`: 신호 대기 중 추돌. 모의 차량 신호로 충격 감지부터 확인 질문·대응까지 보여 준다.
- `tools/record-demo.sh S06 30`: 고속도로 타이어 고장. 대피·견인 경로를 보여 준다.
- `tools/record-demo.sh S03 30`: 에어백 전개. 119가 우선임을 보여 준다.

녹화할 때만 브로드캐스트의 autoAnswers=true를 지정해 픽스처 응답을 재생한다. 수동 응답을 누르면 자동 응답은 중단한다. 영상에 표시되는 모의 신호·규칙 판단·보험 모의 연동 문구를 가리지 않는다.

## 수정 범위

- 수동 질문 응답에서 현재 질문 검사 및 700ms 중복 탭 방지. 모든 일반 트리아지 화면에도 전환 지연 적용.
- 자동 응답 기본 해제. 촬영 명령에서만 명시적으로 활성화.
- 실시간 운전자에 데모 보험·보호자·개인정보를 상속하지 않음.
- 미전송 보호자 알림을 시도·성공으로 기록하지 않고 미연동 안내.
- 모의 보험사 접수번호를 실제 사건 접수 완료로 기록하지 않음.
- 비상등 센서 표시를 방향지시등 지원 여부와 분리.
- 미연동 음성 인식 안내를 정차 후 응답으로 변경. 규칙 기반 보험 판단 출처 표시.

실차 장착 방향·좌석 점유 SDK 값·ADAS·실제 보험사 연동은 별도 검증 과제다.
